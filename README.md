# React Portfolio Website

## Overview

This project is a personal portfolio website developed using React and Vite. The website showcases my profile, skills, projects, resume, and contact information in a responsive and user-friendly interface.

## Features

* Responsive Design
* About Me Section
* Skills Section
* Projects Showcase
* Resume Section
* Contact Section
* Smooth Navigation

## Technologies Used

* React.js
* Vite
* JavaScript
* HTML5
* CSS3
* Git
* GitHub
* Vercel

## Installation

1. Clone the repository

```bash
git clone https://github.com/Akkiali/portfolio-app.git
```

2. Navigate to the project directory

```bash
cd portfolio-app
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment Process

1. Created the portfolio website using React and Vite.
2. Developed reusable React components.
3. Tested the application locally.
4. Initialized Git and pushed the source code to GitHub.
5. Connected the GitHub repository to Vercel.
6. Deployed the application successfully.
7. Verified responsiveness and functionality.

## Challenges Faced

* Learning Git and GitHub workflow for the first time.
* Understanding the deployment process using Vercel.
* Making the portfolio responsive across devices.

## Solutions Implemented

* Used Git version control to manage project files.
* Leveraged Vercel's automatic deployment features.
* Applied responsive CSS styling and testing.
